📖 Lärarrummet för skolor

Allt rektor, IT och dataskyddsombud behöver för att bedöma och godkänna Lärarrummet, på ett ställe.

▶ Prova appen utan att installera

Kort om appen

🔒 Ingen molntjänst

All data finns på lärarens dator. Utvecklaren får aldrig någon data. Inget personuppgiftsbiträdesavtal behövs.

0️⃣ Inga personuppgifter som standard

Nivå 0: inga elevnamn. Nivå 1–2 kräver rektorns beslut i appen och kan låsas av IT.

🛡️ Barnets trygghet

Ingen lärare får något förrän vårdnadshavaren har godkänt hen. Misstankar kan anmälas direkt till rektorn.

🆓 Gratis och öppen källkod

MIT-licens, ingen reklam, ingen telemetri, ingen AI i lärarappen.

♿ Tillgänglig

Granskad mot WCAG 2.1 AA, 0 automatiska fel i ljust och mörkt läge.

🏫 Frivilligt komplement

Ersätter inte lärplattformen. Elever utan appen går inte miste om något.

För IT: tre steg

  1. Installera

    Microsoft Store (granskning pågår): signerad av Microsoft, kan läggas till i Intune som Microsoft Store-app (ny). Store sköter uppdateringarna.

    Installationsprogram: per användare utan administratör, eller för alla användare med /ALLUSERS. Tyst installation: /VERYSILENT /SUPPRESSMSGBOXES /NORESTART.

    ⬇ Senaste versionen IT-paket (ADMX, .reg, Intune)

  2. Godkänn inloggningen med skolkonto (en gång, frivilligt)

    Lärarna kan visa vårdnadshavarna att de har ett konto hos skolan. Appen ber bara om openid, profile och email.

    Microsoft 365: logga in som global administratör eller programadministratör och godkänn. Efteråt visar webbläsaren ett fel om localhost. Det är normalt, godkännandet är sparat.

    Godkänn i Microsoft Entra

    Google Workspace: Administratörskonsolen → Säkerhet → API-kontroller → Hantera åtkomst för tredjepartsappar → Konfigurera ny app → klient-id
    643812673723-33m2dqh36du5mvtio6e2cdpkiafj6sin.apps.googleusercontent.com → Betrodd. Behövs bara om tredjepartsappar är begränsade.

  3. Styr med grupprinciper (valfritt)

    HKLM\SOFTWARE\Policies\Laxspelet Larare: MaxNiva (0, 1 eller 2) låser högsta nivå. Uppdateringar (automatisk, manuell, av). Nätverk: TCP och UDP 8770 i det lokala nätet, HTTPS ut till GitHub och familjerna.

    Detaljer för IT

För rektor: rekommenderad väg

  1. Börja på nivå 0

    Inga personuppgifter behandlas. Låt en lärare prova under en termin, frivilligt för familjerna.

  2. Informera vårdnadshavarna

    Berätta vilka lärare som använder appen, så att vårdnadshavarna vet vilka de ska godkänna. Mall finns.

  3. Vill ni gå vidare till nivå 1–2

    Gör en konsekvensbedömning med dataskyddsombudet, för in i registerförteckningen och fatta ett rektorsbeslut. Allt finns som Word-mallar.

✔ Som rektor i appen ser du anmälningar från vårdnadshavare under 🏫 Skolan, och alla behörighetsbeslut loggas.
